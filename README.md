# 🚀 TCB — Industry-Specific Micro-SaaS Ecosystem

> **The Code Brains (TCB) Micro-SaaS Platform Landing Page**
> A modern, high-conversion landing page showcasing specialized business management solutions tailored for Retail Stores, Personal Finance, and Educational Institutes.

---

## 🌟 Overview

**TCB Ecosystem** powers multi-mode operations for modern businesses and educational institutions with dedicated dashboards and real-time management tools:

- 🏬 **TCB Store (Retail POS & Expense Management)**: All-in-one Point of Sale (POS), inventory tracking, expense management, and Party Khata ledgers.
- 🎓 **TCB School (Educational & Coaching Management)**: Student management, attendance tracking, automated fee reminders, and performance analytics for coaching centers and schools.

---

## ✨ Features

- 🎨 **Emerald & Clean Modern UI**: High-contrast, accessibility-first design language built with Tailwind CSS.
- 📱 **Fully Responsive Layout**: Dynamic user experience across mobile, tablet, and desktop viewports.
- ⚡ **Next.js 14 App Router**: Lightning-fast server-rendered performance and optimized SEO metadata.
- 🔄 **Interactive Showcase & Demos**: Real-time interactive previews of TCB Store and TCB School dashboards.
- 🏷️ **Flexible Pricing & Plans**: Transparent pricing models for solo business owners, growing teams, and enterprise institutes.

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js 18.x** or higher installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Afzalalam-Afzuu/tcb-micro-saas-platform-landing-page.git
   cd tcb-micro-saas-platform-landing-page
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Open [http://localhost:3000](http://localhost:3000) to view the application.
